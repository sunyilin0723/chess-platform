♟ 在线棋类对战

🚀 项目配置指南

刚克隆下来？按以下三步完成配置并启动，约需 3 分钟

1环境要求

确认你的电脑已安装以下软件

软件最低版本说明
Node.js18+运行游戏服务器与管理后台（内置 fetch 需要 18+）
MongoDB4+本地或远程数据库，默认连接 mongodb://localhost:27017
npm随 Node 附带安装依赖

🪟 Windows

Node.js v24.21.0（.msi） MongoDB 8.0.32（.msi）

🍎 macOS（Apple 芯片）

Node.js v24.21.0（.pkg）
MongoDB 安装（Homebrew）：
brew tap mongodb/brew
brew install mongodb-community@8.0
安装完直接启动：
brew services start mongodb-community@8.0

🐧 Ubuntu（Linux）

MongoDB 8.0.32（.deb）
Node.js 安装（命令）：
curl -fsSL https://mirrors.aliyun.com/nodesource/deb_20.x/setup | sudo -E bash -
sudo apt install -y nodejs
安装完启动 MongoDB：
sudo systemctl enable --now mongod
🔍 验证安装：三条命令都出结果、MongoDB 服务为 running 即就绪，再往下走。 
node -v          # 应输出 v18 及以上
npm -v           # 应输出版本号

# MongoDB 是否在运行（三选一，按你的系统来）
sc query MongoDB                 # Windows：STATE 应为 RUNNING
brew services list               # macOS：mongodb-community 应为 started
systemctl is-active mongod       # Linux：应输出 active

2安装依赖

在项目根目录（用户版本/）打开终端，分别进入两个子目录安装

# 游戏服务器依赖
cd 用户系统
npm install

# 管理后台依赖
cd ../管理员系统
npm install

3新建 .env

仓库不含 .env（已被 git 忽略）。请在项目根目录（用户版本/）新建一个名为 .env 的文件，把下面的模板整段复制进去，再按需修改

# 游戏服务器端口
GAME_PORT=3002
# 管理后台端口
ADMIN_PORT=3003
# 数据库地址
MONGO_URI=mongodb://localhost:27017/chess-platform
# 主管理员账号（首次启动管理后台时创建）
ADMIN_USERNAME=admin
ADMIN_PASSWORD=改成你的密码
# 两个服务器共用的通信密钥（两边必须完全一致）
ADMIN_KEY=改成一串随机字符
# 人机验证（留空 = 跳过验证，本地开发建议留空）
TURNSTILE_SITE_KEY=
TURNSTILE_SECRET_KEY=
# 对外域名（公网部署时才填，不带端口，如 https://chess.example.com）
SITE_URL=
# HTTPS（可选）：Cloudflare Origin Certificate，配了就在 443 走 HTTPS
# 留空 = HTTP 启动，本地开发不用配
SSL_CERT_PATH=
SSL_KEY_PATH=
⚠️ 别把 .env 提交进 git：它已被 .gitignore 排除，保持这样即可，密钥泄露会导致他人冒用你的管理员账号。
变量必填说明
GAME_PORT建议游戏服务器端口，默认 3002
ADMIN_PORT建议管理后台端口，默认 3003
MONGO_URI必填数据库地址，如 mongodb://localhost:27017/chess-platform
ADMIN_USERNAME必填主管理员用户名（首次启动管理后台时自动创建）
ADMIN_PASSWORD必填主管理员密码
ADMIN_KEY必填两个服务器共用的通信密钥，必须一致，否则管理后台看不到实时对局
TURNSTILE_SITE_KEY可选人机验证 siteKey；留空 = 跳过验证（本地开发建议留空）
TURNSTILE_SECRET_KEY可选人机验证 secretKey，与上面成对配置
SITE_URL可选对外域名，不带端口（如 https://chess.example.com），部署到公网时填
SSL_CERT_PATH可选Origin 证书路径（相对项目根目录，如 certs/origin.pem）；填写后游戏服在 443 提供 HTTPS，留空走 HTTP
SSL_KEY_PATH可选私钥路径（如 certs/origin.key），与上一项成对使用；私钥别提交进 git（已加入 .gitignore）
💡 最简配置：本地跑通只需填 MONGO_URI、ADMIN_USERNAME、ADMIN_PASSWORD、ADMIN_KEY 四项，其余留默认/留空即可。

4启动服务

先确认 MongoDB 正在运行，然后开两个终端分别启动

# 终端 1 —— 游戏服务器
cd 用户系统
node server.js

# 终端 2 —— 管理后台
cd 管理员系统
node server.js
地址用途
http://localhost:3002欢迎页 / 用户端（游戏入口）
http://localhost:3002/home大厅（需先登录）
http://localhost:3003管理后台（用 ADMIN_USERNAME/PASSWORD 登录）
🌐 用域名访问时不用带端口：配好 Cloudflare Origin 证书（见常见问题）或反向代理后，直接打开 http://你的域名 / https://你的域名 即可，浏览器地址里不需要写 :3002；下面的 localhost:3002 只是本地开发用的地址。

🎉 首次使用

启动成功后的建议操作顺序

1. 注册一个普通账号

打开 http://localhost:3002 → 立即开始 → 注册（新用户自动获得 1200 天梯初始分）

2. 登录管理后台

打开 http://localhost:3003，用 .env 里的 ADMIN_USERNAME / ADMIN_PASSWORD 登录；可在"管理员"页添加子管理员

3. 开一局试试

大厅选择棋类 → 人机对战（三档难度）或输入房间号人人对战

❓ 常见问题

启动报 MongoDB 连接失败？

先确认 MongoDB 服务在运行：Windows 在 services.msc 里找 MongoDB，macOS 执行 brew services list，Linux 执行 systemctl status mongod；服务没起就先启动它（见第 1 步的命令）。服务正常则检查 MONGO_URI 是否写对。

管理后台看不到实时对局？

两端 ADMIN_KEY 必须完全一致，改完需重启两个服务。

改了前端代码没生效？

浏览器强制刷新 Ctrl+F5（HTML 用 ?v=N 版本号控缓存，改动大时版本号会递增）。

注册/举报提示"人机验证失败"？

本地开发建议把 TURNSTILE_SITE_KEY / TURNSTILE_SECRET_KEY 留空（跳过验证）；正式使用需到 Cloudflare 控制台创建 Turnstile 站点，且 hostname 包含你访问用的域名或 localhost。

端口被占用？

修改 .env 中的 GAME_PORT / ADMIN_PORT 后重启。

想用域名直接开 HTTPS（访问不带端口）？

用 Cloudflare Origin Certificate 让 Node 自己在 443 上说 HTTPS：

① Cloudflare 控制台 → SSL/TLS → Origin Server → Create Certificate（域名填你的站点）→ 把 Origin Certificate 全文存成 certs/origin.pem、Private Key 全文存成 certs/origin.key（放在项目根目录，即 .env 同级）；
② .env 填 SSL_CERT_PATH=certs/origin.pem、SSL_KEY_PATH=certs/origin.key，重启游戏服务器，日志出现 [ssl] 已加载 Origin 证书 即成功；
③ Cloudflare 后台 SSL/TLS 加密模式选 Full (strict)——Origin 证书只用于 Cloudflare ↔ 源站这一段，浏览器不认它，别指望 https://localhost 直接通过；
④ 私钥文件已在 .gitignore 里，不要提交进 git。

公网部署要注意什么？

两种做法任选：① 上面的 Origin Certificate 方案，游戏服自己在 443 提供 HTTPS；② 或用 Nginx/Caddy 反代监听 80/443 转发到本机游戏端口，转发必须带 WebSocket 升级头（Upgrade/Connection），否则连不上对局。无论哪种，用户都直接访问域名即可，不用加 :端口；SITE_URL 填不带端口的域名；Turnstile 的 hostname 要包含该域名；MongoDB 不要对公网开放。

配置完成了？

进入站点开始对局，或前往管理后台管理用户
